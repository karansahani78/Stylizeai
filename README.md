
# **🎨 StylizeAI**

**StylizeAI** is an AI-powered image stylization tool that transforms your photos into artwork inspired by renowned artists and styles. Leveraging deep learning techniques, StylizeAI offers a seamless experience to apply artistic effects to your images.

---

## **🖼️ Features**

- **Multiple Artistic Styles**: Choose from a variety of pre-trained styles to apply to your images.  
- **Real-time Preview**: Instantly preview the stylized image before saving.  
- **High-Resolution Output**: Generate high-quality images suitable for printing or sharing.  
- **User-Friendly Interface**: Intuitive design ensures ease of use for all users.  
- **Batch Processing**: Stylize multiple images simultaneously to save time.

---

## **🛠️ Technologies Used**

- **Python 3.8+**  
- **TensorFlow / PyTorch** – Deep learning model implementation  
- **Flask** – Lightweight backend framework  
- **OpenCV** – Image processing  
- **HTML/CSS/JavaScript** – Frontend components

## **🚀 Getting Started**

### **📦 Prerequisites**

- Python 3.8 or higher  
- pip (Python package manager)

### **Installation**

1. **Clone the repository:**

   ```bash
   git clone https://github.com/karansahani78/Stylizeai.git
   cd Stylizeai
   ```

2. **(Optional) Create a virtual environment:**

   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application:**

   ```bash
   python app.py
   ```

5. **Access the app:**

   Open [http://localhost:5000](http://localhost:5000) in your browser.

## **🧠 Model Information**

StylizeAI uses neural style transfer models inspired by the work of [Gatys et al.](https://arxiv.org/abs/1508.06576). These models allow the transfer of artistic style from one image to another using convolutional neural networks.
